# Lektra

**A quiet, offline-first study planner for university students.**

[**Open the app →**](https://gemy21.github.io/Lektra/)

</div>

## What it is

Lektra keeps your weekly lectures, sections and labs alongside quizzes, deadlines,
midterms and finals in one simple calendar. It installs like a phone app, works fully
offline, and stores your data only on your device.

## Built with

- **Vanilla HTML, CSS and JavaScript** — no framework, no build step, no dependencies
- **Service worker + Web App Manifest** — installable PWA with offline support
- **IndexedDB + localStorage** — local storage and an instant first paint
- **Container queries** — responsive, phone-first layout
- **Web Speech API** — optional voice input
- **Canvas** — optional timetable photo processing
- **Puter.js** — optional AI timetable scan

Hosted on **GitHub Pages**.
